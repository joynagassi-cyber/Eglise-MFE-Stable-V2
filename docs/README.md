# Documentation Lumina

Ce répertoire contient la documentation officielle du projet Lumina.

- `guide-utilisateur.md` – guide complet pour les utilisateurs finaux.
- `conventions.md` – conventions de code et d’architecture.
- `backend.md` – détails de l’architecture Supabase, RLS et Realtime.
- `frontend.md` – vue d’ensemble Flutter, thème, navigation et widgets.
- `providers.md` – répertoire de tous les providers Riverpod.
- `api.md` – datasources, appels Supabase et Isar.
- `extensions.md` – extensions Dart et helpers utilitaires.
- `outils-externes.md` – packages tiers et configuration.
- `features/` – documentation par fonctionnalité.
